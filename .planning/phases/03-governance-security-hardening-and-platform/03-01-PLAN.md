    1. Create etl/src/governance/__init__.py:
       - Export key items from classification and ranger_policies modules

    2. Create etl/src/governance/classification.py:
       - SensitivityLevel enum: PUBLIC, INTERNAL, CONFIDENTIAL, RESTRICTED (with string values)
       - CLASSIFICATION_RULES: list of (regex_pattern, SensitivityLevel) tuples
         - RESTRICTED: ssn, social_security, tax_id, taxpayer, account_number, routing_number, credit_card, card_number, bank_account
         - CONFIDENTIAL: email, phone, mobile, address, street, city, zip, postal, date_of_birth, dob, salary, compensation
         - INTERNAL: (default for non-PUBLIC columns in bronze/silver/gold schemas)
         - PUBLIC: symbol, ticker, exchange, currency, market, trade_date, report_date
       - classify_column(column_name: str) -> SensitivityLevel: matches column name against rules, returns highest sensitivity match
       - classify_table_columns(columns: list[str]) -> dict[str, SensitivityLevel]: batch classification
       - get_columns_by_level(columns: dict[str, SensitivityLevel], level: SensitivityLevel) -> list[str]: filter helper

    3. Create etl/src/governance/ranger_policies.py:
       - Uses apache_ranger.client.ranger_client.RangerClient and apache_ranger.model.ranger_policy classes
       - create_masking_policy(service, policy_name, tag_or_resource, groups, mask_type) -> dict: builds Ranger masking policy (policyType=1)
         - mask_type choices: MASK, MASK_SHOW_LAST_4, MASK_SHOW_FIRST_4, MASK_HASH, MASK_NULL, MASK_NONE, custom
       - create_row_filter_policy(service, policy_name, catalog, schema, table, groups, filter_expr) -> dict: builds row filter policy (policyType=2)
       - create_tag_policy(tag_service, policy_name, tag_name, groups, mask_type) -> dict: tag-based masking policy
       - create_access_policy(service, policy_name, catalog, schema, table, groups_permissions) -> dict: standard access policy (policyType=0)
       - All functions return policy dicts that can be submitted via RangerClient.create_policy()
       - NOTE: Functions build policy structures without requiring a live Ranger connection (testable in unit tests)

    4. Create infra/docker/ranger/bootstrap-policies.py:
       - Script that runs against Ranger Admin to seed initial policies
       - Uses RangerClient to connect to ranger-admin:6080
       - Creates Trino resource service named "trino" if not exists
       - Creates tag service named "trino_tag" if not exists
       - Seeds access policies:
         - data_admin: full access to all catalogs/schemas/tables
         - data_engineers: full DML on iceberg catalog (except sensitive_ns schema)
         - data_readers: SELECT only on iceberg catalog (except sensitive_ns schema)
       - Seeds tag-based masking policies:
         - RESTRICTED tag: MASK_NULL for data_readers, MASK_SHOW_LAST_4 for data_engineers, MASK_NONE for data_admin
         - CONFIDENTIAL tag: MASK_HASH for data_readers, MASK_SHOW_LAST_4 for data_engineers, MASK_NONE for data_admin
         - INTERNAL tag: MASK_NONE for all (no masking, just classified)
         - PUBLIC tag: MASK_NONE for all
       - Seeds row-filter policies:
         - gold.trades: filter by business_unit matching user's group (wealth_mgmt, investment_banking, risk_management)
         - gold.positions: same pattern
       - Seeds classification tags on example columns:
         - gold.trades.ssn -> RESTRICTED
         - gold.trades.account_number -> RESTRICTED
         - gold.trades.trader_email -> CONFIDENTIAL
         - gold.trades.business_unit -> INTERNAL
         - gold.trades.symbol -> PUBLIC
       - Idempotent: checks if policies exist before creating (uses policy names as keys)
