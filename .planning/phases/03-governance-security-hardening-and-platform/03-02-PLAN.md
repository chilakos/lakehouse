    1. Create etl/src/governance/freshness_tracker.py:
       - FreshnessStatus enum: GREEN ("On time"), YELLOW ("Warning"), RED ("Stale")
       - FreshnessSLA dataclass:
         - table_name: str
         - expected_update_interval_hours: float (e.g., 24.0 for daily)
         - warning_threshold_hours: float (e.g., 26.0 -- 2 hours grace)
         - critical_threshold_hours: float (e.g., 48.0 -- missed SLA)
       - DEFAULT_SLAS: dict mapping table patterns to SLAs:
         - "gold.*": 24h expected, 26h warning, 48h critical
         - "silver.*": 12h expected, 14h warning, 24h critical
         - "bronze.*": 6h expected, 8h warning, 12h critical
       - check_table_freshness(last_updated: datetime | None, sla: FreshnessSLA) -> FreshnessStatus:
         - None -> RED
         - hours_since = (now - last_updated).total_seconds() / 3600
         - <= expected -> GREEN, <= warning -> GREEN, <= critical -> YELLOW, > critical -> RED
       - get_freshness_badge(status: FreshnessStatus) -> dict: returns {"status": "green", "label": "On time", "icon": "check-circle"} style dict for Grafana/UI
       - get_all_freshness(table_slas: dict, last_updated_map: dict) -> list[dict]: batch freshness check returning list of {table, status, hours_since_update, sla_hours}
