       - `minio_client` (session-scoped): Creates a boto3 S3 client configured for MinIO (endpoint_url from env or http://localhost:9000, aws_access_key_id/secret from env or admin/admin123456). Yields client.
       - `s3_client` (session-scoped): Creates a boto3 S3 client for AWS S3 (uses default credential chain). Yields client. Skips if AWS credentials are not available.
