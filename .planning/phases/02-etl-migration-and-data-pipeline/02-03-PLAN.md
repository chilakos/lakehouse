    1. Create `etl/src/pipelines/incremental.py`:
       - `IncrementalConfig` dataclass: watermark_column (str), source_table (str), tolerance_seconds (int = 0)
       - `get_last_watermark(spark, iceberg_table: str, watermark_column: str) -> Any | None`: runs `SELECT MAX({watermark_column}) FROM lakehouse.{iceberg_table}`, returns None if table empty or no rows
       - `incremental_extract(spark, source_query_template: str, watermark_column: str, last_watermark) -> DataFrame`: builds query with WHERE clause filtering by watermark > last_watermark. If last_watermark is None, does full extract (no filter).
       - `merge_incremental(spark, target_table: str, df: DataFrame, merge_key: str) -> None`: performs MERGE INTO for upserts using Iceberg's merge-on-read capability. Matches on merge_key, updates all columns on match, inserts new rows.

    2. Create `etl/src/pipelines/bronze/positions_ingest.py`:
       - `PositionsBronzePipeline(BasePipeline)`:
         - source_data parameter (list[dict] or path)
         - PipelineConfig: target_layer=BRONZE, target_table="positions"
         - extract() creates DataFrame from source data using positions_schema()
         - transform() adds metadata columns (raw-as-is per locked Bronze decision)

    3. Create `etl/src/pipelines/silver/positions_clean.py`:
       - `PositionsSilverPipeline(BasePipeline)`:
         - Reads from lakehouse.bronze.positions
         - Deduplicates by position_id (keep latest ingestion_ts)
         - Validates market_value > 0 (business rule)
         - Drops Bronze metadata columns
         - Entity-centric output (one row per position per as_of_date, per locked Silver decision)

    4. Create `etl/src/pipelines/bronze/mainframe_ingest.py`:
       - `MainframeBronzePipeline(BasePipeline)`:
         - Parameters: spark, copybook_path (str), data_path (str), source_system (str), batch_id (str)
         - extract(): reads using spark.read.format("cobol") with Cobrix options: copybook, encoding="ebcdic", is_record_sequence="true", schema_retention_policy="collapse_root"
         - transform(): adds metadata columns, casts packed decimal fields to Decimal type
         - PipelineConfig: target_layer=BRONZE, target_table dynamically set from copybook name
         - NOTE: This pipeline will SKIP gracefully in tests if Cobrix JAR is not available (per research open question about JAR compatibility)
