    1. Create `etl/src/quality/__init__.py` (empty).

    2. Create `etl/src/quality/scanner.py`:
       - `@dataclass QualityCheckResult`: check_name (str), outcome (str: "pass"|"fail"|"warn"), metric_value (Any), threshold (Any), is_critical (bool)
       - `run_soda_checks(spark_session, df, checks_yaml_path: str, critical_check_names: list[str], data_source_name: str = "spark_df") -> dict`:
         - Creates Soda Scan instance
         - Sets scan_definition_name = "etl_quality_gate"
         - Sets data_source_name
         - Adds spark_session via scan.add_spark_session()
         - Creates temp view from df and passes to scan
         - Loads SodaCL YAML file via scan.add_sodacl_yaml_file()
         - Executes scan
         - Returns dict with: "passed" (bool), "critical_failures" (list of QualityCheckResult for critical checks that failed), "warnings" (list of QualityCheckResult for non-critical checks that failed), "all_results" (list of all QualityCheckResult)
         - IMPORTANT: Use Soda Core's programmatic scan API for DataFrames -- do NOT use configuration.yml (per research pitfall #2)

    3. Create SodaCL YAML check files per research Pattern 2:
       - `etl/src/quality/checks/bronze_trades.yml`:
         - Critical: schema check for required columns (trade_id, trade_date, symbol, side, quantity, price)
         - Critical: missing_count(trade_id) = 0 (primary key not null)
         - Critical: duplicate_count(trade_id) = 0 (primary key unique)
         - Advisory: missing_percent(account_id) < 5
         - Advisory: valid_min(price) >= 0
         - Advisory: valid_min(quantity) > 0
       - `etl/src/quality/checks/silver_trades.yml`:
         - Critical: duplicate_count(trade_id) = 0
         - Critical: missing_count(trade_id) = 0
         - Advisory: valid values for side IN ("BUY", "SELL")
       - `etl/src/quality/checks/gold_trading_metrics.yml`:
         - Critical: missing_count(symbol) = 0
         - Advisory: valid_min(trade_count) > 0
         - Advisory: valid_min(total_notional) >= 0

    4. Create `etl/src/quality/reconciliation.py`:
       - `@dataclass ReconciliationResult`: table_name (str), source_row_count (int), target_row_count (int), row_count_match (bool), source_checksum (Decimal|None), target_checksum (Decimal|None), checksum_match (bool|None), source_aggregates (dict), target_aggregates (dict), aggregate_matches (dict[str, bool]), passed (bool)
       - `reconcile_table(spark, source_df: DataFrame, target_table: str, checksum_columns: list[str] | None = None, aggregate_columns: dict[str, str] | None = None, tolerance: Decimal = Decimal("0.01")) -> ReconciliationResult`:
         - Computes source row count from source_df.count()
         - Computes target row count from lakehouse.{target_table} via SparkSQL
         - If checksum_columns provided, computes SUM of each column for both source and target, checks within tolerance
         - If aggregate_columns provided (e.g., {"price": "AVG", "quantity": "SUM"}), computes and compares
         - Sets passed = row_count_match AND (checksum_match if applicable) AND all aggregate_matches
