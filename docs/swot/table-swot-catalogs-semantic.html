Reading the table: Polaris wins on Iceberg purity, credential vending, Snowflake/Databricks cloud burst, and enterprise support. Gravitino wins on multi-format breadth, legacy HMS bridge, table maintenance, lineage, and UI. For RBC’s pure-Iceberg estate, Polaris is the right primary catalog. Gravitino adds value only if Teradata’s HMS tables need to be federated during the multi-year decoupling programme.
