Data Governance for BCBS 239 Compliance

The governance stack provides end-to-end data lineage, pipeline observability, and metadata cataloging. Together, these capabilities satisfy BCBS 239 requirements for data aggregation accuracy, completeness, timeliness, and adaptability.

  • OpenLineage: Standardized lineage event format emitted by Airflow and PySpark at every pipeline stage. Captures run, job, and dataset-level metadata.
  • Marquez (:5000): OpenLineage-compatible lineage server storing provenance metadata. The Marquez Web UI (:3000) provides interactive lineage graph exploration.
  • Grafana (:3001): Dashboards for pipeline SLA monitoring, data freshness tracking, and alerting. The grafana-reporter (:8686) generates PDF compliance evidence for audit.
  • OpenMetadata (:8585): Data catalog for asset discovery, classification, and quality scoring. Elasticsearch (:9200) powers full-text search across all metadata.

Lineage evidence from Marquez, SLA dashboards from Grafana, and data classification from OpenMetadata combine to provide a unified governance view that satisfies BCBS 239 auditability requirements.
