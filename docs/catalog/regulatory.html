BCBS 239

Basel Committee principles requiring financial institutions to have strong risk data aggregation capabilities and internal risk reporting practices.

Compliance Context

The lakehouse supports BCBS 239 compliance through end-to-end data lineage tracking via OpenLineage/Marquez, automated data quality checks, and freshness SLA monitoring.

PII

Personally Identifiable Information -- data that could identify a specific individual.

Compliance Context

PII columns are automatically classified via regex rules (classification.py) and masked for non-privileged users via Ranger tag-based masking policies. Classification levels: PUBLIC, INTERNAL, CONFIDENTIAL, RESTRICTED.

Value at Risk (VaR)

Maximum expected loss over a specified time horizon at a given confidence level.

Compliance Context

VaR at 95% and 99% confidence levels are core BCBS 239 risk metrics. Computed in the gold.risk_exposure table and exposed via the Cube risk_exposure semantic layer for consistent cross-consumer reporting.

Expected Shortfall

Average loss in the tail beyond the VaR threshold, capturing the severity of worst-case scenarios.

Compliance Context

ES is increasingly required by regulators as a more coherent risk measure than VaR. Like VaR, it is computed in gold.risk_exposure and exposed via the Cube semantic layer.
