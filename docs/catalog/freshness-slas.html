Data Freshness SLAs

Update intervals and status thresholds by data layer

Generated: 2026-03-30

Data freshness is monitored using traffic-light SLA status. Each dataset in the lakehouse has a defined Service Level Agreement specifying the expected update interval and thresholds for warning and critical status. SLA breaches trigger automated alerts via Grafana.

Status Definitions

GREEN On time — Data is current -- within expected update interval
YELLOW Warning — Data is stale -- past warning threshold but within critical threshold
RED Stale — Data is critically stale -- past critical threshold, or never updated

SLA Thresholds by Layer

gold.*

GREEN ≤ 24.0h expected interval
YELLOW > 26.0h warning threshold
RED > 48.0h critical threshold

silver.*

GREEN ≤ 12.0h expected interval
YELLOW > 14.0h warning threshold
RED > 24.0h critical threshold

bronze.*

GREEN ≤ 6.0h expected interval
YELLOW > 8.0h warning threshold
RED > 12.0h critical threshold

Freshness is tracked in Grafana dashboards and the OpenMetadata catalog. SLA breaches trigger automated alerts to the data engineering team. Thresholds shown below are extracted from freshness_tracker.py at documentation build time.
