### Benchmark Queries

```sql
-- Full scan (COUNT)
SELECT COUNT(*) FROM {namespace}.trades

-- Filtered scan

-- Aggregation (GROUP BY)
SELECT symbol, SUM(notional) AS total_notional
FROM {namespace}.trades GROUP BY symbol

-- Join (trades x positions)
SELECT t.symbol, p.market_value
FROM {namespace}.trades t
JOIN {namespace}.positions p ON t.account_id = p.account_id

-- Point lookup
SELECT * FROM {namespace}.trades WHERE trade_id = 42
```
