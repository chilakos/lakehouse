CI/CD Workflow

From pull request to production: CI gates, environment promotion, and deploy workflows

1Overview

Code moves from feature branch to production through a series of CI gates and environment promotions. Every pull request triggers automated checks. Merges to environment branches trigger deployments via Terraform. The full path is: feature branch -> PR to dev -> merge -> PR to staging -> merge -> PR to main -> production deploy + smoke tests.

2CI Pipeline (ci.yml)

Triggered on every pull request to main, staging, or dev. All jobs must pass before merge is allowed.

CI Jobs

  • python-lint (Python Lint & Format): Runs ruff check . and ruff format --check . in etl/. Enforces line-length 120, pycodestyle, pyflakes, isort, pep8-naming, pyupgrade, bugbear, simplify rules.
  • python-test (Python Unit Tests): Runs pytest tests/unit/ -x --tb=short. Unit tests only -- no Docker services required. Fast feedback loop.
  • cube-yaml-validate (Cube YAML Validation): Validates Cube semantic model YAML structure and verifies glossary term links against OpenMetadata seed data.
  • terraform-validate (Terraform Validate): Runs terraform init -backend=false && terraform validate in infra/terraform/.
  • terraform-fmt (Terraform Format Check): Runs terraform fmt -check -recursive infra/terraform/. Enforces consistent HCL formatting.

3Environment Promotion

Three environments with increasing gates at each stage.

Dev Environment

  • Trigger: Push to dev branch
  • Workflow: deploy-dev.yml
  • Terraform workspace: dev
  • Post-deploy: Optional integration tests
  • Purpose: Early integration testing, feature validation

Staging Environment

  • Trigger: Push to staging branch
  • Workflow: deploy-staging.yml
  • Terraform workspace: staging
  • Post-deploy: Integration tests run against staging environment
  • Purpose: Pre-production validation, performance testing

Production Environment

  • Trigger: Push to main branch
  • Workflow: deploy-prod.yml
  • Terraform workspace: prod
  • Post-deploy: Smoke tests -- Nessie health (/q/health/ready), Trino health (/v1/info)
  • Purpose: Live production serving 40+ engineers and BI consumers

4Deploy Workflows

All deploy workflows use OIDC authentication with AWS and Terraform workspaces for environment isolation.

Common Steps

  • Checkout code
  • Configure AWS credentials via OIDC (aws-actions/configure-aws-credentials@v4)
  • Setup Terraform 1.7 (hashicorp/setup-terraform@v3)
  • terraform init
  • terraform workspace select -or-create {env}
  • terraform plan -var-file=environments/{env}/terraform.tfvars -out=tfplan
  • terraform apply tfplan

deploy-dev.yml

Triggered on push to dev branch. Uses dev Terraform workspace and environments/dev/terraform.tfvars. Optional integration tests after deploy.

deploy-staging.yml

Triggered on push to staging branch. Uses staging Terraform workspace. Runs integration tests against the staging environment after successful deploy.

deploy-prod.yml

Triggered on push to main branch. Uses prod Terraform workspace. Runs smoke tests with retries: Nessie health check (curl -sf --retry 3 --retry-delay 10 https://nessie.lakehouse.internal:19120/q/health/ready), Trino health check (curl -sf --retry 3 --retry-delay 10 https://trino.lakehouse.internal:8443/v1/info).

5Branch Naming

Use the feature/TICKET-description convention for all feature branches.

Convention

  • Format: feature/TICKET-description (e.g., feature/DATA-123-add-positions-pipeline)
  • CI parses the branch prefix for environment routing and PR labeling
  • Bugfix branches: bugfix/TICKET-description
  • Hotfix branches: hotfix/TICKET-description

Promotion Flow

  • 1. Create feature/TICKET-desc branch from dev
  • 2. Open PR to dev -- CI runs lint + unit tests + Terraform validate
  • 3. Merge to dev -- deploy-dev.yml deploys to dev environment
  • 4. Open PR from dev to staging -- CI gates re-run
  • 5. Merge to staging -- deploy-staging.yml deploys + integration tests
  • 6. Open PR from staging to main -- CI gates re-run
  • 7. Merge to main -- deploy-prod.yml deploys + smoke tests
