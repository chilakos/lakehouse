BasePipeline class extends ABC

Abstract base class for all medallion ETL pipelines.

MethodArgsReturnsDescription
extract DataFrame Extract source data and return as DataFrame.
transform df: DataFrame DataFrame Transform the extracted DataFrame.
validate_schema df: DataFrame bool Validate DataFrame schema against the target schema.
add_metadata_columns df: DataFrame, source_system: str, batch_id: str DataFrame Add Bronze-layer metadata columns to a DataFrame.
write df: DataFrame None Write validated DataFrame to the target Iceberg table.
run_quality_checks df: DataFrame dict[str, Any] Run data quality checks on the DataFrame using Soda Core.
execute dict[str, Any] Orchestrate the full pipeline: extract -> transform -> validate -> write.
Usage Example 
from src.pipelines.base import BasePipeline, PipelineConfig, MedallionLayer
from pyspark.sql.types import StructType, StructField, StringType

class MyPipeline(BasePipeline):
    def extract(self):
        return self.spark.read.csv(self.config.source_path)
    def transform(self, df):
        return df.filter(df["status"] == "active")

config = PipelineConfig(
    name="my-pipeline",
    target_layer=MedallionLayer.BRONZE,
    target_table="my_table",
    target_schema=StructType([StructField("id", StringType())]),
)
result = MyPipeline(spark, config).execute()
