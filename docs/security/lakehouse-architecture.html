Confirmed decisions

  • Privacera — authorization, masking, audit
  • Polaris — primary Iceberg REST catalog
  • Fabric Import — BI/AI surface (ADR-010)
  • MinIO — on-prem S3-compatible storage
  • OpenLineage — BCBS 239 lineage
  • OCP — deployment platform
  • Teradata OTF — removed from scope

  • Polaris incubating risk — acceptable?
  • Tokenization for PCI scope reduction?

Compliance coverage

  • OSFI B-13 — Privacera + Vault + SIEM
  • PCI DSS 4.0 — DDM + audit + WORM
  • BCBS 239 — OpenLineage + snapshots
  • PIPEDA — Anonymization + retention
  • Data residency — all primary data on-prem CA
  • Fabric DDM — enforced via Import mode only
